## Errors/Failures

**DiffBragg CUDA Cleanup Bug (DIFFBRAGG-001)**
- **Error**: `GPUassert: invalid argument diffBraggCUDA.cu:708` occurring during final forward pass after refinement convergence.
- **Location**: simtbx library, diffBraggCUDA.cu line 708 (attempted cudaFree on unallocated GPU pointers).
- **Suspected Root Cause**: simtbx C++ code attempts to free GPU memory twice or on invalid pointers during cleanup phase.
- **Workaround**: Hardcode devId=0 (GPU mode) to avoid triggering the broken CPU cleanup path (devId=-1).
- **Evidence**:
  - Prior loop (2025-10-29T030352Z) captured refinement success (2101 iterations, F=678151 converged) but failed at forward baseline export.
  - Current loop verified torch 2.4.1+cu121 and nanobrag_torch import; no mitigation available within Environment Freeze policy.
  - CLI hardcodes devId=0 (refine_one.py:261), so production workflows bypass the bug automatically.
