## Summary

Galph iteration 33 concluded a multi-loop investigation into zero-output intensities from the nanobrag_torch simulator during canonical golden dataset capture. After systematic exploration across six prior dwell cycles, analysis identified the root cause: the simulator's `compute_physics_for_position` function computes Miller indices using real-space crystal axes instead of the documented reciprocal vectors. This violates the forward-pass physics model and causes structure-factor lookups to return default zeros. The loop drafted a spec-compliant fix targeting the simulator's vector math and prepared implementation artifacts for the next phase.

- `get_structure_factor(h, k, l)` returned non-zero values when tested in isolation
