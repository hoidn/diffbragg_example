## Errors/Failures

No errors occurred during iteration 36 itself. However, the log documents two prior engineering blockers that were resolved:

1. **DIFFBRAGG-001** (iter 35, resolved): Legacy DiffBragg forward-only pipeline crashed due to unguarded `cudaFree` in `simtbx_project/simtbx/diffBragg/src/diffBraggCUDA.cu:705-713` and missing `<cassert>` in `diffuse_util.h`. Applied targeted bugfix patch; rebuilt `simtbx_diffBragg_ext.so` (md5 1506a48bee414ffcec041083b1496a44). Root cause: GPU cleanup hook assumed CUDA context availability without null checks.

2. **HKL-ORIENT-001** (iter 35, resolved): Single-source nanoBragg2 simulator cached incident beam vector with wrong sign convention, pushing computed Miller indices outside the loaded HKL grid (h∈[18,48], k∈[14,53], l∈[23,61]) and resulting in 0% HKL hit rate and zero torch intensities. Root cause: Multi-source code path already negates source directions; single-source default was inconsistent. Fixed by negating `detector.beam_vector` in `Simulator.__init__`.
