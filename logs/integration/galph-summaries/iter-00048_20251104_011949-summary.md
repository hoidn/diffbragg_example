## Decisions/Rationales

- **Root cause identified as geometry mismatch**: Systematic peak offsets (consistent Y+6, X+1 pixel pattern) across ROI samples point to detector geometry/beam-center misalignment rather than physics divergence, confirmed via prototype instantiation with DIALS convention eliminating the ~6 px shift.

- **DIALS convention over CUSTOM basis vectors**: Chose DetectorConvention.DIALS with explicit XYZ rotations to preserve BEAM pivot alignment, avoiding the distance_corrected=-0.231m offset and beam-center drift observed with CUSTOM basis vectors (torch direct beam at [1250.1,1267.0] vs refGeom [1243.6,1266.0]).

- **Deferred multi-panel handling**: Implementation plan includes guard clause for multiple panels, but iteration 48 focused on single-panel refGeom case (raises clear error if multiple panels detected).

- **Maintained Environment Freeze discipline**: No package installs or environment modifications proposed; all fixes use existing imports (scitbx, numpy, nanobrag_torch).

- **Promoted inline probe to reusable script**: ROI offset summarizer elevated to plans/active/NANOBRAG-GOLDEN-001/bin/ to enable reliable invocation across future iterations per input.md structure guidelines.
