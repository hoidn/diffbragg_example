## Decisions/Rationales

**Why Euler conversion failed previously**: The `scitbx.matrix.sqr(...).r3_rotation_matrix_as_x_y_z_angles()` function returns angles compatible with Z→Y→X composition order, but nanobrag_torch's `angles_to_rotation_matrix` composes rotations as X→Y→Z with a different canonical form. This ordering mismatch caused the reconstructed basis vectors to deviate from the original DIALS orientation, accumulating 4–8 pixel localization errors across ROI samples.

**Why manual derivation is correct**: The analytical Euler angles directly invert the rotation matrix columns (corresponding to fast/slow/normal axes) using the standard X→Y→Z Euler angle convention matching torch's implementation. Testing on the reference geometry confirms <2e-16 reconstruction error.

**Why fix is scoped to detector rotations only**: Beam vector alignment (torch sample→source vs dxtbx source→sample sign) is expected per HKL-ORIENT-001 and requires no change. Rotation is orthogonal to beam-center positioning; fixing rotation alone will isolate whether remaining offsets stem from separate geometry effects.

## Errors/Failures

1. **scitbx Euler conversion mismatch** — `r3_rotation_matrix_as_x_y_z_angles()` produces angles that, when reapplied via torch's `angles_to_rotation_matrix`, fail to reconstruct the original dxtbx basis (norm difference ~0.005, sign flips on Y/Z). This represents a fundamental incompatibility in rotation composition conventions between scitbx and nanobrag_torch.

2. **math.domain error in prior Euler attempt** — When used with `scitbx.r3_rotation_matrix_as_x_y_z_angles()` on the column-stacked [fast, slow, normal] matrix, the function attempted asin(1.46e5), indicating the input was not a valid rotation matrix. The function assumes R[0,2] is the sine of the middle Euler angle, but for DIALS geometry this assumption fails.

**Root causes**:
- Incompatible Euler angle conventions between libraries (scitbx uses Z→Y→X; torch uses X→Y→Z)
- Lack of test coverage for basis vector reconstruction after Euler conversion
- Prior attempt did not validate that the result matched dxtbx axes
