Collocate this with simulate_forward_once refactor to keep PyTorch runtime contracts unified and enable testing/prototyping without external dependencies.

**Decision 5: Plan Phase A (planning), B (implementation), C (verification) Rather Than Single Loop**
- **Rationale**: Gradcheck implementation is complex (5 parameter types, strict tolerances, diagnostics JSON, environment guards). Breaking into 3 phases allows Galph to gather diagnostic feedback from Ralph's implementation pass, verify thresholds are appropriate, and adjust pytest fixture or tolerance tuning without rework.
