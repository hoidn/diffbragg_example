## Decisions/Rationales

**Decision 1: Persist refined MTZ as fixture**
- **Rationale**: The refined structure factors generated during golden dataset creation are currently discarded; persisting them avoids recomputation and makes the baseline reproducible and version-controlled.
- **Impact**: Enables DB_AT_024 to use accurate amplitude data matching the canonical golden dataset.

**Decision 2: Update test to prefer refined MTZ with fallback**
- **Rationale**: Graceful fallback to `scaled.mtz` maintains backward compatibility while allowing new tests to benefit from refined inputs without forcing immediate changes across all test paths.
- **Impact**: Reduces risk of breaking existing tests while enabling incremental improvement.

**Decision 3: Remove provisional xfail once thresholds are met**
- **Rationale**: Current xfail with documented metrics (corr_median=0.0489, localization=0.0%) serves as documentation of known gaps. Once refined inputs are available, the test should enforce hard assertions matching canonical golden dataset performance (corr≈0.99, localization≈0.94).
- **Impact**: Converts acceptance test from diagnostics-only to a hard gate on mapping quality.
