## Errors/Failures

1. **Intensity explosion on N_cells (2025-11-04T190000Z → 203000Z)**
   - Symptom: DB_AT_024 corr regressed from +0.019 to -0.043; masked Bragg mean jumped to 5.9e11 ADU (2.3e4× normal)
   - Root cause: N_cells parameter ([36,28,26]) applied in TorchCrystalConfig but no corresponding sample-clipping logic in the torch bridge
   - Evidence: Calibration sweep toggling N_cells alone reproduced failure exactly; toggling flux/exposure/beamsize had zero effect
   - Suspected fix: Either gate N_cells application entirely or implement nanoBragg-style sample clipping in torch bridge before applying N_cells

2. **Beam config not wired to crystal**
   - Symptom: Flux/beamsize/exposure metadata passed but no observable change in output
   - Root cause: beam_config created but not passed to TorchCrystal constructor in nanobrag_torch, so metadata is lost
   - Evidence: Flux toggle in calibration sweep had zero correlation impact
   - Suspected fix: Route beam_config object into TorchCrystalConfig instantiation
