## Errors/Failures and Root Causes

### Test Failure: `test_torch_diagnostics_metadata`

**Error:**
```
TypeError: '>=' not supported between instances of 'MagicMock' and 'float'
```

**Location:** `dbex/refine_one.py:449`

**Root Cause:**
- The `_write_torch_outputs` function aggregates ROI scores with: `sum([s >= 0.5 for s in scores])`
- When unit tests mock `score_trainer.roi_check`, they return `MagicMock` instances instead of numeric values
- No coercion to `float` occurs before comparison, causing TypeError
- Additionally, `np.mean(scores)` on empty or non-numeric collections produces `nan` without clear diagnostics

**Suspected Fix:**
- Add explicit `float()` coercion when collecting scores
- Guard empty collections before aggregation
- Emit stable numeric values to HDF5 attributes
