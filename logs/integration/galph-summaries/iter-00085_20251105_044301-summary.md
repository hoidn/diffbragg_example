## Decisions/Rationales

**Decision:** Rebaseline Stage A nucleus acceptance from 5% to 0.1% improvement

**Rationale:**
- Telemetry probe shows empirical ceiling of ~0.15% improvement on canonical dataset
- Large log_scale delta (+3.68) indicates scale optimization working, but warm-start initialization (scale=62.66 from calibration hint) leaves optimizer near local optimum
- Single crystal DoF (log_cell_a_delta) contributing zero gradient—confirming minimal parameter set provides limited optimization leverage
- Specs mandate LBFGS + closure semantics and Stage A nucleus with "tiny parameter set" (docs/spec-db-workflow.md:30-38, plans/nanobrag_integration_plan.md:176-219)
- Implementation is correct and preserves autograd; threshold gap is dataset/scope characteristic, not a bug
- Documented path forward: expand Stage A DoFs (cell_b/c, angles, orientation) in future iteration to achieve higher improvement targets
