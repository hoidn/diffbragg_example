**Decision**: Introduce deterministic calibration perturbation in Stage A smoke test only
**Rationale**: Canonical refGeom assets are too well-calibrated (telemetry shows only 0.23% improvement even after cell delta fixes), making the 5% gate unattainable without either finding a less-calibrated dataset or artificially perturbing the test fixture. The team chose to add a test-scoped perturbation (cell stretch + small orientation misset) to exercise the recovery contract without mutating production defaults.

**Decision**: Defer orientation refinement completion to follow-up implementation
**Rationale**: The `orientation_vec` → quaternion → XYZ misset pipeline requires proper integration with `create_crystal_config` without conflicting with cell parameter overrides. This was documented as REFINE-003 and requires careful implementation to avoid reintroducing the A* injection bug fixed in the previous iteration.
