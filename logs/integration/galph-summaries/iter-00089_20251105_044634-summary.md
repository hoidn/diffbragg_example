## Errors/Failures and Suspected Root Causes

**HKL Grid Incompatibility (REFINE-005)**:
- **Error signature**: 0% HKL hit rate (0/6,224,001 lookups) when Stage A refinement uses perturbed geometry
- **Root cause**: `build_structure_factor_grid` indexes reflections to the original crystal's reciprocal lattice; when `orientation_vec` and cell parameters are perturbed, nanobrag_torch computes Miller indices in the perturbed basis that fall outside the precomputed grid bounds
- **Consequence**: Zero Bragg peak intensity, preventing validation of ≥5% masked-MSE improvement gate
- **Evidence**: Orientation telemetry implementation is correct (misset_deg tensors survive CrystalConfig, quaternion→XYZ conversion is differentiable), but cannot be exercised on perturbed geometry without grid rebuild
