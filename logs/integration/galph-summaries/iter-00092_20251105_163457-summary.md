## Decisions/Rationales

**Pivot from HKL Grid Rebuild to Halo+Interpolation**:
- **Prior state**: 2025-11-05T070500Z implementation successfully plumbed deterministic misset (U_delta) and achieved 98.07% HKL hit rate with nearest-neighbor lookup, but improvement plateaued at 0.22%
- **Root cause**: Nearest-neighbor |F| lookup produces effectively zero orientation gradients even with deterministic perturbation (+2/+1/+1% cell, +1.5° Z-misset)
- **Prior attempts summary** (from fix_plan):
  - 2025-11-05T044720Z: HKL probe revealed 100% in-bounds fraction but fractional coordinates (max 0.5)
  - 2025-11-05T060833Z: Nearest-neighbor test showed <0.3% improvement
  - 2025-11-05T070500Z: Misset plumbing validated but ≥5% gate remains xfailed
- **Strategic shift**: Rather than rebuild HKL grid to integer indices (original Phase 1 plan), enable tricubic interpolation to handle fractional HKL coordinates naturally, providing smooth gradients for orientation refinement
- **Technical approach**: Add optional ±1 halo padding to `build_structure_factor_grid` so interpolator has valid neighbor values; gate interpolation via `RefinementConfig` flag to preserve nearest-neighbor fallback for datasets lacking halo

**Implementation Scope**:
- Three production files targeted: bridge (grid builder), refinement orchestrator, test harness
- Exit xfail only after achieving ≥5% improvement with interpolation enabled
- Preserve deterministic perturbation magnitudes (REFINE-004) for reproducibility
- Maintain gradient flow (GRADIENT-001) and device/dtype neutrality
