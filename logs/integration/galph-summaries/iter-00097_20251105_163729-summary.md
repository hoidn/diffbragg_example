## Decisions/Rationales

1. **Stage B Default Disabled**: Stage B will be opt-in via config/CLI to maintain stability of existing Stage C smoke tests and nucleus paths until Stage B clears its acceptance gate.

2. **Shell Mode First**: Implementation focuses on shell-modifier mode rather than per-reflection mode to avoid parameter explosion and maintain computational efficiency.

3. **Halo Grid Requirement**: Stage B enablement will be refused unless `hkl_metadata["has_halo"]` is true, enforcing the differentiable interpolation requirement.

4. **Positive Modifiers**: Shell modifiers use positive transforms (softplus/log-exp) to avoid violations of scaling requirements from SCALE-001/002.

5. **Telemetry Integration**: Stage B telemetry will be integrated into existing `_write_torch_outputs` framework with new `/torch_diagnostics/stage_B` groups.

6. **Acceptance Gate**: Placeholder improvement threshold set at ≥3% loss decrease within ≤30 steps, subject to calibration against canonical refGeom dataset in Phase 5.
