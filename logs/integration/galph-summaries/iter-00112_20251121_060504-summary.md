## Decisions/Rationales

- **Root cause isolation**: Traced NaN/Inf failures to denominator clamping at scalar 1.0 rather than a configurable floor value, matching spec requirements.
- **Implementation scope**: CLI flag approach allows end-users to tune sigma_floor per dataset (photons vs ADU conventions), while RefinementConfig threading ensures consistency across all three refinement stages.
- **Telemetry strategy**: Recording configured floor value + clamp fraction in RefinementTelemetry and /torch_diagnostics enables debugging of numerical stability issues and future optimization.
- **Test targeting**: Mapped selectors test_stage_a_expansion, test_stage_b_shell_modifiers, test_stage_c_detector_microslip plus CLI metadata test to validate floor implementation across all paths.
