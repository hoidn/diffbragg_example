## Decisions/Rationales

**Critical Decision**: Proceed to Phase C1 Branch G (geometry fix) rather than Phase C Branch O (parameterization fix) or Phase C Branch P (tooling fix).

**Rationale**:
1. **Phase A0 evidence**: Symmetric strain component (logm(U) = 1.4e-3) dominates the 4e-5 A* gap; antisymmetric (pure rotation) is ≈1000× smaller (1.4e-7).
2. **Phase A2 evidence**: Deriving B_ideal from mapping's MOSFLM A* via cctbx cell recovery yields identical strain (H2 rejected: both B_ideal variants produce same A* mismatch), proving the root cause is not cell recovery procedure but baseline B_ideal selection.
3. **Phase B1 evidence**: Gradients at zero deltas are non-zero and massive (orientation_vec magnitude ≈2.88e8), indicating the zero point is not a critical point—Adam's departure is legitimate, not a derivative bug.
4. **Phase A3 evidence**: Forward models computed via both parameterizations using identical nanobrag_torch exhibit 24.5% chi-squared difference (mapping χ²≈2.39e6 vs explicit χ²≈2.98e6), confirming the 2.6× global chi-squared mismatch is a parameterization artifact, not simulator parity bug.
5. **Minimal change principle**: Geometry fix (compute B_ideal from MOSFLM A* matrix itself) is smallest and most direct change, preserves all Adam/loss machinery, and directly targets the 1.4e-3 symmetric strain root cause.
