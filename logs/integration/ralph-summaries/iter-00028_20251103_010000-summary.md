## Errors/Failures

### MTZ-FLEX-001: miller_array customized_copy requires flex.double arrays

**Error Message:**
```
RuntimeError: Conversion of given type of miller_array to MTZ format is not supported.
  File "capture_forward.py", line 181, in main
    Fopt.as_mtz_dataset(column_root_label="F").mtz_object().write(...)
```

**Root Cause:** Amplitude refinement loop accumulates refined structure factors in a numpy array (Famps). When passed to `customized_copy()` for MTZ dataset creation, cctbx/iotbx expects scitbx.array_family.flex types. Plain numpy arrays bypass flex validation, causing downstream MTZ writer to reject the array.

**Suspected Root Cause Depth:**
- cctbx miller_array.customized_copy() requires flex.double/flex.int/flex.bool for data/sigmas/indices
- numpy.ndarray lacks deep_copy() method and flex-specific validation hooks
- iotbx.mtz checks array type during add_miller_array(); rejects non-flex inputs

**Resolution Applied:** Convert Famps to flex.double before customized_copy (3-line patch, tested against baseline MTZ write)
