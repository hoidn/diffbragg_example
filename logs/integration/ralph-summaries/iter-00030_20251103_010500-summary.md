## Implementation Details

### Blocking Issue Analysis

The JSON serialization crash stems from incomplete type conversion in the nested torch config metadata. The failing code path:

```python
torch_meta["crystal"]["mosflm_a_star"]  # Contains numpy.float32 elements
json.dump(torch_meta, f, indent=2)      # TypeError at json.dump
```

The fix requires a comprehensive converter that recursively traverses the metadata structure:

```python
def to_native(obj):
    """Recursively convert numpy/torch types to Python primitives."""
    if isinstance(obj, dict):
        return {k: to_native(v) for k, v in obj.items()}
    elif isinstance(obj, (list, tuple)):
        return [to_native(v) for v in obj]
    elif isinstance(obj, torch.Tensor):
        return to_native(obj.tolist())
    elif isinstance(obj, np.ndarray):
        return to_native(obj.tolist())
    elif isinstance(obj, (np.floating, np.integer)):
        return obj.item()
    else:
        return obj
```
