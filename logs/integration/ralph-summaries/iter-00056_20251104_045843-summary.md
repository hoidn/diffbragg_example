## Decisions/Rationales

- **Task Dependency Assessment**: The input specifies "prove same-seed reproducibility and different-seed independence with canonical parity tensors" which requires either: (1) actual forward simulator runs with controllable seeds, or (2) pre-computed determinism artifacts. Neither is currently available.
- **Blocked on Upstream**: `nanobrag_torch.Simulator` is not importable from available sources, blocking the ability to generate forward passes needed for determinism validation.
- **Golden Data Gap**: Golden data provides detector/geometry configuration but no seed vectors or pre-computed same-seed/diff-seed tensor pairs required for the test scaffold.
- **Documentation Alignment**: The specification clearly mandates metrics (array_equal for same-seed, correlation≤0.7 for diff-seed) but lacks the execution layer to compute them.

## Errors/Failures

- **ImportError: cannot import Simulator**: Attempting to verify nanobrag_torch availability failed with `ImportError: cannot import name 'Simulator' from 'nanobrag_torch'`. The module exists but does not export the expected simulator interface.
- **Root Cause**: The nanobrag_torch backend is documented as forthcoming in `spec-db-conformance.md:6-8` ("currently placeholders; not wired to existing DiffBragg CLI").
- **Blocker Type**: External dependency — requires upstream `nanobrag_torch` to provide functional Simulator class with determinism-aware seed handling.
