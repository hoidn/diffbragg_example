## Decisions/Rationales

- **Float64 intermediate for numerics**: Used float64 intermediate during ADU-to-photon conversion and cast back to float32 to preserve precision per pitfall guidance in input.md:9
- **IQR-based outlier filtering**: Applied Tukey's IQR method (1.5*IQR) on background-subtracted pixels when computing global_scale_hint to avoid scale inflation from rare high-intensity pixels
- **Fallback for empty pixels**: Set `global_scale_hint = 1.0` when no valid ROI pixels exist to avoid downstream division-by-zero in optimization
- **Strict validation**: Reject `adu_per_photon <= 0` with actionable error message citing spec-db-workflow.md:20 before any conversion
- **No double-scaling**: Ensured photon conversion path does not interfere with existing SCALE-002 spot_scale_override semantics per finding CONFIG-001
- **Skip-graceful tests**: Tests use canonical assets when available (refGeom.expt, refGeom.refl, scaled.mtz, 747_mask.pkl) but generate synthetic fixtures when missing to prevent false negatives

## Errors/Failures

- **Initial global_scale_hint issue** (root cause: over-aggressive outlier filtering removing most signal): Resolved by switching from p10/p90 percentiles to IQR-based filtering (p25/p75 ± 1.5*IQR), which better preserves the core of the distribution while filtering true outliers.
- No other blocking errors encountered; full test suite passes cleanly without regressions.
