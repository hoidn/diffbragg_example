## Decisions and Rationales

- **Refined MTZ approach**: Store refined structure factors as separate fixture file rather than embedding in experiment, allowing tests to load them optionally. This provides graceful fallback to raw MTZ if refined version unavailable.

- **Test assertion strategy**: Replace provisional xfail with hard assertions to enforce passing thresholds. If thresholds cannot be met with current fixture set, the failure signals explicitly that geometry alignment is needed rather than silently accepting degraded metrics.

- **Architecture citation in error messages**: Error messages explicitly reference architectural findings (SCALE-003/SCALE-004 in docs/findings.md) so that failures provide actionable guidance about what fixture modifications are required.

## Errors and Failures

**Critical Blocker: DB-AT-024 Threshold Failure**

**Measured Metrics:**
- Correlation median: 0.0352
- Localization success rate: 0%

**Required Thresholds:**
- Correlation: >= 0.2
- Localization success rate: >= 90%

**Root Cause Analysis:**

The refined structure factors (|F|opt) were optimized during DiffBragg refinement using the workspace's refined detector and crystal geometry. These refined amplitudes, when simulated with the refined geometry, produce excellent metrics (corr=0.81, localization=100% as seen in golden capture metrics). However, DB-AT-024 loads the test fixture `refGeom.expt` which contains the **original, unrefined geometry**. When refined structure factors are simulated with mismatched unrefined geometry, Bragg peaks shift and intensities diverge dramatically from the target (unrefined data), causing correlation to collapse.

**Evidence:**
- Golden dataset with refined geometry: `plans/active/MAP-SCALE-001/reports/2025-11-04T120500Z/refined_capture/metrics.json` shows corr=0.81, localization=100%
- DB-AT-024 with unrefined geometry: `plans/active/MAP-SCALE-001/reports/2025-11-04T120500Z/mapping_metrics.json` shows corr=0.0352, localization=0%
- The ~23x difference in correlation directly correlates with geometry mismatch (detector/crystal positions drift by ~6 pixels per GEOMETRY-002 finding)
