- **Shared loss helper**: Centralizing the variance-weighted chi-squared calculation via `_compute_variance_weighted_loss` prevents divergence between stages and ensures all stages report the same denominator (sigma-floor clamped variance), resolving prior unit mismatch where Stage A used legacy `(Σ diff^2)/(Σ variance)` while B/C summed per-pixel `(diff^2 / variance)`
- **Canonical baseline propagation**: Recording Stage A's final metrics (chi-squared value, iteration count, ROI count, detector distances) in telemetry enables downstream gates to compare against a single canonical reference and validate improvement without mixing incompatible measurement units
- **Stage B extended timeout**: Initial Stage B smoke hit the 120 s default harness timeout; reran with longer budget and captured successful telemetry, confirming the shared helper eliminated the prior NaN/Inf gradient errors that blocked Stage B
- **Strict selector knobs**: Using `DBEX_SMOKE_DETECTOR_SIZE=full` and explicit telemetry path captures ensures Stage C detector offset reduction meets the ≥80% spec requirement without resource guardrails
