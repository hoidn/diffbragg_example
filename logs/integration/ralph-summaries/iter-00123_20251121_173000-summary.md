# Decisions/Rationales

- **Metadata-first ingestion**: External_lookup metadata takes lowest precedence after CLI options, eliminating forced `--sigma-map` requirements when metadata is available
- **Strict validation**: Validate tile count, shape, and value constraints (positive, finite) before stacking into float32 array; fail fast with actionable error messages per spec-db-core.md:20-34 and 32-68
- **Provenance tracking**: Record sigma source as `"external_lookup"` in torch_diagnostics telemetry to enable downstream trace validation and debugging
- **Backward compatibility**: CLI args remain unchanged; metadata ingestion is transparent fallback when no CLI overrides are supplied
