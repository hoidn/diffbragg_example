# Decisions/Rationales

**Metadata fixture integration**: Reused existing `smoke_sigma_source` fixture rather than introducing new configuration, maintaining consistency with prior Stage A/B/C smoke test patterns. Metadata path (`sp.proc/idx-0000_sigma_metadata`) aligns with external-lookup harvesting logic already present in `_load_external_lookup_sigma_map()`.

**Provenance tracking**: Added explicit `sigma_readout_provenance` field to RefinementInputs to propagate source lineage end-to-end, allowing downstream telemetry (mapping metrics, HDF5 attrs) to report the actual sigma origin instead of assuming CLI override.

**Reference value extraction**: Computed median of sigma_readout values (within loss mask if available, fallback to full array) to provide a single representative sigma value for telemetry reporting, supporting both CLI scalar and spatially-varying metadata scenarios.

**Parameterized CLI test**: Rather than creating separate test functions for CLI and metadata paths, parameterized `test_torch_diagnostics_metadata()` over source/value pairs so both branches exercise identical assertion logic, reducing test duplication and maintenance burden.
